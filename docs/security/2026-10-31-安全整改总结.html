立即严重S2 · 微信回调验签被绕过

影响：伪造支付成功、零元结算。动作：await pay.verifySign(...)，补单测覆盖异步返回值。

立即严重S3 · 支付宝回调可跨应用伪造

影响：跨应用 / 跨订单结算。动作：校验 app_id、seller_id、金额与渠道归属。

立即高危H1 · 渠道 token 作商家鉴权

影响：跨商家订单与对账泄露。动作：引入商家身份令牌，渠道 token 仅作渠道标识。现状：11-01 提交已停止聚合大厅批量下发，单店换取仍返回渠道 token。

立即高危H2 · 默认超管口令

影响：全站接管。动作：核验生产凭据，强制轮换并禁用默认账号。

立即高危H3 · 生产 DEV_BYPASS 开关

影响：零元购、绕过真实支付。动作：生产启动强制全部为 false，缺失时拒绝启动。

立即高危H5 · 回调金额未与订单应付比对

影响：金额篡改、少付多结算。动作：结算前比对回调金额与订单应付。

本周严重S4 · 银行卡加密密钥硬编码默认值

影响：提现账户密文可被解密。动作：密钥改为必填环境变量，缺失拒绝启动。

本周高危H4 · 生产 Playground / debug / verbose

影响：schema 与内部栈泄露。动作：生产配置显式关闭。

本周中危M1 · 登录 / 验证码限流缺口

影响：暴力破解、接口刷量。动作：统一限流与失败锁定策略。

本周中危M2 · SQL 拼接注入面

影响：数据泄露 / 破坏。动作：按调用点复核并参数化。

近期中危M3 · 上传校验不足
