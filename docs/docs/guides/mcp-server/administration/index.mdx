Give your operators access to manage the MCP server without giving them general store-settings access.

Operators work in the dashboard's **MCP Server** section or through the Admin GraphQL API.

## Grant the permissions

The MCP dashboard and Admin API run under a dedicated `McpServer` permission pair. Grant it to the operators
who manage the AI integration.

| Task | Permission |
|---|---|
| View the tool registry and active grants | `ReadMcpServer` |
| View [call logs and stats](/guides/mcp-server/observability/) | `ReadMcpServer` |
| Turn a tool on or off | `UpdateMcpServer` |
| Revoke a grant | `UpdateMcpServer` |
| Prune expired call logs | `UpdateMcpServer` |
| [Approve an admin consent request](/guides/mcp-server/oauth-consent/#approve-a-client-as-an-administrator) | `UpdateMcpServer` |

:::info
`ReadMcpServer` does not expose captured request or response bodies. Reading a call log's `input`, `output`, or
`clientIp` also requires `ReadCustomer`.
:::

## Registry visibility

The tool-registry query returns the full registry. It is not filtered per caller, so any holder of
`ReadMcpServer` sees every tool.
