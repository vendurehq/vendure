### getApplicableTaxRate

<MemberInfo kind="method" type={`(ctx: <a href='/reference/typescript-api/request/request-context#requestcontext'>RequestContext</a>, targetOrZone: <a href='/reference/typescript-api/services/tax-rate-service#taxratetarget'>TaxRateTarget</a> | <a href='/reference/typescript-api/entities/zone#zone'>Zone</a> | <a href='/reference/typescript-api/common/id#id'>ID</a>, taxCategory: <a href='/reference/typescript-api/entities/tax-category#taxcategory'>TaxCategory</a> | <a href='/reference/typescript-api/common/id#id'>ID</a>) => Promise<<a href='/reference/typescript-api/entities/tax-rate#taxrate'>TaxRate</a>>`}   />

Returns the applicable TaxRate based on the specified target and TaxCategory. Used when calculating Order
prices. The most specific rate wins: a country rate for `target.countryCode`, then a rate for
`target.zone`, then a default rate with a value of 0.

Passing a Zone or zone ID instead of a target finds zone rates only.
### findOverlappingZoneRates

<MemberInfo kind="method" type={`(ctx: <a href='/reference/typescript-api/request/request-context#requestcontext'>RequestContext</a>) => Promise<<a href='/reference/typescript-api/services/tax-rate-service#zonetaxrateoverlap'>ZoneTaxRateOverlap</a>[]>`}   />

Returns the countries which two or more zone rates of the same TaxCategory match, and which
have no country rate for that TaxCategory. For such a country, the rate depends on which Zone
the [TaxZoneStrategy](/reference/typescript-api/tax/tax-zone-strategy#taxzonestrategy) returns; [AddressBasedTaxZoneStrategy](/reference/typescript-api/tax/address-based-tax-zone-strategy#addressbasedtaxzonestrategy) returns the first.
Nothing is changed.
