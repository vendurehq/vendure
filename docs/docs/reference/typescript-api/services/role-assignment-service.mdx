## RoleAssignmentService

<GenerationInfo sourceFile="packages/core/src/service/services/role-assignment.service.ts" sourceLine="53" packageName="@vendure/core" since="4.0.0" />

Contains methods relating to [RoleAssignment](/reference/typescript-api/entities/role-assignment#roleassignment) entities — the `(user, role, channel)`
triples which grant a User a Role's permissions on a specific Channel.

Write methods do not perform authorization themselves: callers are responsible for
asserting that the active user may grant the Roles involved (see
`RoleService.assertActiveUserCanGrantRoles`). All writes go through entity-based
repository operations so that [SessionService](/reference/typescript-api/services/session-service#sessionservice)'s entity subscriber observes them
and evicts the affected User's cached sessions — permission changes therefore take
effect on the User's next request.

### replaceUserAssignmentsOnChannel

<MemberInfo kind="method" type={`(ctx: <a href='/reference/typescript-api/request/request-context#requestcontext'>RequestContext</a>, userId: <a href='/reference/typescript-api/common/id#id'>ID</a>, roleIds: <a href='/reference/typescript-api/common/id#id'>ID</a>[], channelId: <a href='/reference/typescript-api/common/id#id'>ID</a> = ctx.channelId) => Promise<void>`}   />

Replaces the User's Role assignments on the given Channel with the given Roles,
leaving assignments on other Channels untouched.

This implements the `roleIds` inputs of the administrator and API-key mutations, which
are read as "replace this User's Roles on the active Channel" — a `roleIds` grant
always carried a channel in the request (the `vendure-token` header), it was just
never part of the write. The `roleIds` inputs are deprecated since 4.0.0 in favor of
the `roleAssignments` vocabulary and will be removed in v5.0.0. Once they are gone, the
only remaining caller is the external-authentication administrator grant
(`ExternalAuthenticationService.createAdministratorAndUser`); re-evaluate whether
this method stays at that point.

Publishes a [RoleAssignmentEvent](/reference/typescript-api/events/event-types#roleassignmentevent) for the added and for the removed pairs.
