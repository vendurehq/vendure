A ShippingMethod is used to apply a shipping price to an [Order](/reference/typescript-api/entities/order#order). It is composed of a
[ShippingEligibilityChecker](/reference/typescript-api/shipping/shipping-eligibility-checker#shippingeligibilitychecker) and a [ShippingCalculator](/reference/typescript-api/shipping/shipping-calculator#shippingcalculator). For a given Order,
the `checker` is used to determine whether this ShippingMethod can be used. If yes, then
the ShippingMethod can be applied and the `calculator` is used to determine the price of
shipping.

### applyQuotes

<MemberInfo kind="method" type={`(ctx: <a href='/reference/typescript-api/request/request-context#requestcontext'>RequestContext</a>, order: <a href='/reference/typescript-api/entities/order#order'>Order</a>) => Promise<<a href='/reference/typescript-api/shipping/shipping-calculator#shippingcalculationresult'>ShippingCalculationResult</a>[]>`}  since="4.0.0"  />

Runs the ShippingCalculator and returns every ShippingOption it returns, cheapest first.
A calculator which returns a single result yields an array of one. If a calculator returns
several results which do not each have a unique `code`, the chosen option could not be
identified when the Order is recalculated, so an error is logged and no options are returned:
the ShippingMethod is then unavailable for the Order, while other ShippingMethods still are.
