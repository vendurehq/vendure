A RoleAssignment grants a [User](/reference/typescript-api/entities/user#user) the permissions of a [Role](/reference/typescript-api/entities/role#role) on a specific
[Channel](/reference/typescript-api/entities/channel#channel). It is the source of truth for permission resolution: a Role is a
channel-agnostic template, and the RoleAssignment supplies the channel scope at the
moment the Role is granted to a User. This allows a single Role definition to be
shared across many Users, each scoped to their own Channels.

}
