A TaxRate defines the rate of tax to apply to a [ProductVariant](/reference/typescript-api/entities/product-variant#productvariant) based on three factors:

1. the ProductVariant's [TaxCategory](/reference/typescript-api/entities/tax-category#taxcategory)
2. the target of the rate: either a country [Region](/reference/typescript-api/entities/region#region), or a [Zone](/reference/typescript-api/entities/zone#zone) ("applicable" being defined
   by the configured [TaxZoneStrategy](/reference/typescript-api/tax/tax-zone-strategy#taxzonestrategy)). Exactly one of the two is set. A country rate
   takes precedence over a zone rate for the country of the order's shipping address.
3. the [CustomerGroup](/reference/typescript-api/entities/customer-group#customergroup) of the current Customer
