A ProductVariant represents a single stock keeping unit (SKU) in the store's inventory.
Whereas a [Product](/reference/typescript-api/entities/product#product) is a "container" of variants, the variant itself holds the
data on price, tax category etc. When one adds items to their cart, they are adding
ProductVariants, not Products.

<MemberInfo kind="property" type={`<a href='/reference/typescript-api/entities/product-variant-price#productvariantprice'>ProductVariantPrice</a>[]`}  since="4.0.0 - No longer an eager relation"  />

The prices of the ProductVariant, one per Channel and currency.

Not loaded by default. Request the relation to read every price.
`ProductVariantService.getProductVariantPrices()` returns the prices of the active Channel.
[ProductPriceApplicator](/reference/typescript-api/service-helpers/product-price-applicator#productpriceapplicator) adds the prices of the active Channel when it prices the
variant, so a priced variant may carry only those: saving it leaves the other prices
untouched.
