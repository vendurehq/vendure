A Role represents a collection of permissions which determine the authorization
level of a [User](/reference/typescript-api/entities/user#user). A Role is a channel-agnostic template: the Channels on
which its permissions apply are determined per-User by [RoleAssignment](/reference/typescript-api/entities/role-assignment#roleassignment)s.
