### metadata

<MemberInfo kind="property" type={`Record<string, unknown>`}  since="4.0.0"  />

Optional data about the calculation, for example the price rule that applied. Vendure does not
save it. The [DefaultOrderItemPriceCalculationStrategy](/reference/typescript-api/orders/default-order-item-price-calculation-strategy#defaultorderitempricecalculationstrategy) returns the metadata of the
[ProductVariantBuyerPriceStrategy](/reference/typescript-api/products-stock/product-variant-buyer-price-strategy#productvariantbuyerpricestrategy), so an outer layer can read it, for example to write it
to the OrderLine custom fields.
