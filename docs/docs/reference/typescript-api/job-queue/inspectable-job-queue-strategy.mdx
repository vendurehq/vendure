### useEntityIdStrategyForJobIds

<MemberInfo kind="property" type={`boolean`} default={`true`}  since="3.8.1"  />

Whether the Admin API encodes and decodes job ids with the configured
[EntityIdStrategy](/reference/typescript-api/configuration/entity-id-strategy#entityidstrategy). This is correct when job ids are database primary keys,
as with the [SqlJobQueueStrategy](/reference/typescript-api/job-queue/sql-job-queue-strategy#sqljobqueuestrategy).

Set this to `false` if the job ids are generated by the job queue itself, as with the
BullMQJobQueueStrategy. The ids are then passed through the Admin API unchanged. Otherwise
an id which the EntityIdStrategy cannot decode, such as a UUID with the default
[AutoIncrementIdStrategy](/reference/typescript-api/configuration/entity-id-strategy#autoincrementidstrategy), cannot be used to look up the job.
