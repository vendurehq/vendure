Returns the number of decimal places of the given [MoneyStrategy](/reference/typescript-api/money/money-strategy#moneystrategy), which is
[DEFAULT_MONEY_PRECISION](/reference/typescript-api/money/default_money_precision#default_money_precision) unless the strategy sets `precision`.

*Example*

```ts
const precision = getMoneyPrecision(configService.entityOptions.moneyStrategy);
const majorUnits = amount / 10 ** precision;
```
