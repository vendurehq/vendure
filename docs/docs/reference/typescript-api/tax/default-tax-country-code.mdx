The default rule for the country whose country [TaxRate](/reference/typescript-api/entities/tax-rate#taxrate)s apply. It is used when the
configured [TaxZoneStrategy](/reference/typescript-api/tax/tax-zone-strategy#taxzonestrategy) does not implement `determineTaxCountryCode()`, and a strategy
that does can call it to keep the default for some cases.

It returns the country of the Order's shipping address, or `undefined` when there is no Order or
no shipping country.

*Example*

```ts
determineTaxCountryCode(ctx: RequestContext, channel: Channel, activeTaxZone: Zone, order?: Order) {
    if (isBusinessCustomer(order)) {
        return undefined;
    }
    return defaultTaxCountryCode(channel, activeTaxZone, order);
}
```
