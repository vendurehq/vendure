## applyPreset

<GenerationInfo sourceFile="packages/core/src/data-import/presets/apply-preset.ts" sourceLine="57" packageName="@vendure/core" since="4.0.0" />

Applies a base-data preset to the default Channel, in one transaction. The preset's data and the
`vendure.seed.preset` sentinel commit together, or nothing is written.

It refuses with a [SeedError](/reference/typescript-api/import-export/presets#seederror):

- `core.preset-unknown` or `core.preset-invalid-option` when the name or the options are wrong;
- `core.preset-database-not-empty` when the database is not empty: it has countries, zones,
  tax categories or rates, shipping or payment methods, products, more than one Channel, or a
  preset sentinel.

Errors are never swallowed: any failure rolls the transaction back and is thrown.

*Example*

```ts
import { applyPreset, bootstrapWorker } from '@vendure/core';

const { app } = await bootstrapWorker(config);
const result = await applyPreset(app, 'single-country', { country: 'NZ', currency: 'NZD' });
await app.close();
```

## SeedErrorCode

<GenerationInfo sourceFile="packages/core/src/data-import/presets/seed-errors.ts" sourceLine="23" packageName="@vendure/core" since="4.0.0" />

The codes of a [SeedError](/reference/typescript-api/import-export/presets#seederror).

- `core.preset-unknown`: no preset has the name. Details: `{name, available}`.
- `core.preset-invalid-option`: an option is missing, unknown or invalid. Details:
  `{preset, option, reason}`.
- `core.preset-database-not-empty`: the database already has setup data or a preset sentinel.
  Details: [PresetDatabaseNotEmptyDetails](/reference/typescript-api/import-export/presets#presetdatabasenotemptydetails).
- `core.scenario-invalid`: a scenario pack could not be loaded, or its manifest is invalid.
  Details: `{package, reason}`.
- `core.scenario-preset-mismatch`: the database was not seeded with the scenario's preset.
  Details: `{scenario, preset, appliedPreset?}`.
- `core.scenario-already-seeded`: the database was already seeded with a scenario. Details:
  `{appliedScenario}`.

```ts title="Signature"
type SeedErrorCode = | 'core.preset-unknown'

    | 'core.preset-database-not-empty'
    | 'core.scenario-invalid'
    | 'core.scenario-preset-mismatch'
    | 'core.scenario-already-seeded'
```
