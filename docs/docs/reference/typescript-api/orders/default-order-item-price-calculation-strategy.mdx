The default [OrderItemPriceCalculationStrategy](/reference/typescript-api/orders/order-item-price-calculation-strategy#orderitempricecalculationstrategy). It returns the unit price that the configured
[ProductVariantBuyerPriceStrategy](/reference/typescript-api/products-stock/product-variant-buyer-price-strategy#productvariantbuyerpricestrategy) calculates for the Customer of the Order, with the OrderLine
custom fields as the pricing data. With the [DefaultProductVariantBuyerPriceStrategy](/reference/typescript-api/products-stock/product-variant-buyer-price-strategy#defaultproductvariantbuyerpricestrategy), this is
the price of the ProductVariant. The result includes the `metadata` of the buyer price strategy, so an
outer layer can read it from the result of `inner`.

It uses `ProductVariantService.calculateBuyerPriceForOrder()`, so it must be initialized with `init()`
before use. Vendure does this for the configured strategy.
