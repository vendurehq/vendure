## ShippingCalculator

<GenerationInfo sourceFile="packages/core/src/config/shipping-method/shipping-calculator.ts" sourceLine="85" packageName="@vendure/core" />

The ShippingCalculator is used by a [ShippingMethod](/reference/typescript-api/entities/shipping-method#shippingmethod) to calculate the price of shipping on a given [Order](/reference/typescript-api/entities/order#order).

*Example*

```ts
const flatRateCalculator = new ShippingCalculator({
  code: 'flat-rate-calculator',
  description: [{ languageCode: LanguageCode.en, value: 'Default Flat-Rate Shipping Calculator' }],
  args: {
    rate: {
      type: 'int',
      ui: { component: 'currency-form-input' },
    },
    taxRate: {
      type: 'int',
      ui: { component: 'number-form-input', suffix: '%' },
    },
  },
  calculate: (ctx, order, args) => {
    return {
      price: args.rate,
      taxRate: args.taxRate,
      priceIncludesTax: ctx.channel.pricesIncludeTax,
    };
  },
});
```

## Several options per ShippingMethod

A calculator may instead return an array of results, one for each ShippingOption it offers. This suits
carrier APIs which return several services with a price for each. Give every result a `code` which is
unique within the array, so the chosen option can be identified when the Order is recalculated, and a
`name` to show to the customer.

The customer chooses an option with `setOrderShippingMethod(shippingMethods: [{ shippingMethodId, shippingOptionCode }])`.
Without a code, the cheapest option is used. The chosen code is stored as `ShippingLine.shippingOptionCode`.
Each time the Order is recalculated the calculator runs again and the result with the stored code is used.
If that code is no longer returned, or the calculator returns nothing, the ShippingLine falls back to the
cheapest option of any eligible ShippingMethod, as it does when a ShippingMethod becomes ineligible. The
transition to `ArrangingPayment` is refused if the chosen option is no longer offered.

A calculator which calls a carrier API should therefore return the last rates it got for the Order
when the carrier cannot be reached, rather than nothing: an empty result replaces the customer's
choice, and throwing fails the whole recalculation of the Order.

*Example*

```ts
const carrierCalculator = new ShippingCalculator({
  code: 'carrier-rates',
  description: [{ languageCode: LanguageCode.en, value: 'Live carrier rates' }],
  args: {},
  calculate: async (ctx, order) => {
    const rates = await carrierApi.getRates(order);
    return rates.map(rate => ({
      code: rate.serviceCode,
      name: rate.serviceName,
      price: rate.amount,
      priceIncludesTax: false,
      taxRate: 20,
    }));
  },
});
```

### code

<MemberInfo kind="property" type={`string`}  since="4.0.0"  />

Identifies this ShippingOption within its ShippingMethod, e.g. a carrier service code such as
`'ups_ground'`. Required, and unique within the array, when the calculator returns more than one
result: otherwise an error is logged and the ShippingMethod is unavailable for the Order. Stored on
the ShippingLine as `shippingOptionCode` when the option is chosen.

Each recalculation of the Order looks the chosen option up by this code, so it must stay the same
from one call to the next. Use the carrier's service-level code (Shippo's `servicelevel.token`,
for example), not an id the carrier generates for each rate request (Shippo's rate `object_id`),
which would never match and make every recalculation fall back to the cheapest option.
### name

<MemberInfo kind="property" type={`string`}  since="4.0.0"  />

The name of this ShippingOption to show to the customer, e.g. `'UPS Ground'`. Stored on the
ShippingLine as `shippingOptionName` when the option is chosen.

## CalculateShippingFn

<GenerationInfo sourceFile="packages/core/src/config/shipping-method/shipping-calculator.ts" sourceLine="180" packageName="@vendure/core" />

A function which implements the specific shipping calculation logic. It takes an [Order](/reference/typescript-api/entities/order#order) and
an arguments object and should return the shipping price as an integer in cents.

Should return a [ShippingCalculationResult](/reference/typescript-api/shipping/shipping-calculator#shippingcalculationresult) object, or an array of them if the ShippingMethod
offers several options. Returning `undefined` or an empty array means the ShippingMethod is not
available for the Order.

type CalculateShippingFn<T extends ConfigArgs> = (

    method: ShippingMethod,
