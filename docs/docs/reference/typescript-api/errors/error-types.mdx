## NoBuyerPriceError

<GenerationInfo sourceFile="packages/core/src/common/error/errors.ts" sourceLine="58" packageName="@vendure/core" since="4.0.0" />

This error is thrown when the [ProductVariantBuyerPriceStrategy](/reference/typescript-api/products-stock/product-variant-buyer-price-strategy#productvariantbuyerpricestrategy) gives no price for the buyer of
an OrderLine, see `ProductVariantService.calculateBuyerPriceForOrder()`. A new OrderLine with no price
is not added. An OrderLine that is already in the Order keeps its current price.

It is an [IllegalOperationError](/reference/typescript-api/errors/error-types#illegaloperationerror), so the GraphQL error code is `ILLEGAL_OPERATION`.
