## isEnabledInChannel

<GenerationInfo sourceFile="packages/core/src/service/helpers/channel-enabled-checker/channel-enabled-checker.ts" sourceLine="41" packageName="@vendure/core" since="4.0.0" />

Decides whether a [Product](/reference/typescript-api/entities/product#product) or [ProductVariant](/reference/typescript-api/entities/product-variant#productvariant) is available in a Channel, from its
global `enabled` value and its `enabled` value in that Channel (`ProductChannel.enabled` /
`ProductVariantChannel.enabled`, exposed in the Admin API as `enabledInChannel`).

The global value is a master switch: the entity is available in a Channel only if it is enabled
globally and enabled in that Channel. `enabledInChannel` is `undefined` if the entity is not
assigned to the Channel, in which case it is not available there either.

This is the pure form of [ChannelEnabledChecker](/reference/typescript-api/service-helpers/channel-enabled-checker#channelenabledchecker), for code which already has both values,
such as search indexers.

## ChannelEnabledChecker

<GenerationInfo sourceFile="packages/core/src/service/helpers/channel-enabled-checker/channel-enabled-checker.ts" sourceLine="107" packageName="@vendure/core" since="4.0.0" />

Checks and sets whether Products and ProductVariants are available in a Channel. A Product or
ProductVariant is available in a Channel only if it is enabled globally (`enabled`) *and*
enabled in that Channel (the `enabled` column of its [ProductChannel](/reference/typescript-api/entities/product-channel#productchannel) /
[ProductVariantChannel](/reference/typescript-api/entities/product-variant-channel#productvariantchannel) row, `enabledInChannel` in the Admin API). See
[isEnabledInChannel](/reference/typescript-api/service-helpers/channel-enabled-checker#isenabledinchannel).

Use this helper rather than reading `enabled` directly when deciding what customers can see or
buy in a Channel.

*Example*

```ts
export class MyCustomService {
  constructor(private connection: TransactionalConnection,
              private channelEnabledChecker: ChannelEnabledChecker) {}

  getAvailableVariants(ctx: RequestContext, productId: ID) {
    const qb = this.connection
      .getRepository(ctx, ProductVariant)
      .createQueryBuilder('variant')
      .where('variant.productId = :productId', { productId });
    this.channelEnabledChecker.applyToQuery(ctx, qb, ProductVariant);
    return qb.getMany();
  }
}
```
