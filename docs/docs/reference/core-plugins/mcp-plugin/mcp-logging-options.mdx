Controls how MCP tool calls are logged and retained. Every call is recorded as an
[McpToolCallLog](/reference/core-plugins/mcp-plugin/mcp-tool-call-log#mcptoolcalllog) row and published as an `McpToolCallEvent`.

```ts title="Signature"
interface McpLoggingOptions {
    ttlDays?: number;
    capture?: McpLogCapture;
    redact?: McpLogRedactFn;
    maxBodyBytes?: number;
    retentionSchedule?: McpRetentionSchedule;
    captureClientIp?: boolean;
}
```
