[RequestContext](/reference/typescript-api/request/request-context#requestcontext), the input, and, when a tool needs to know who is calling,
[McpCallerInfo](/reference/core-plugins/mcp-plugin/mcp-caller-info#mcpcallerinfo).

### execute

<MemberInfo kind="method" type={`(ctx: <a href='/reference/typescript-api/request/request-context#requestcontext'>RequestContext</a>, input: I, caller?: <a href='/reference/core-plugins/mcp-plugin/mcp-caller-info#mcpcallerinfo'>McpCallerInfo</a>) => Promise<O> | O`}   />

The tool's implementation. The server calls it with a [RequestContext](/reference/typescript-api/request/request-context#requestcontext) for the caller,
the validated input, and [McpCallerInfo](/reference/core-plugins/mcp-plugin/mcp-caller-info#mcpcallerinfo). The caller info is always passed, though the
parameter is optional so a tool that ignores it can leave it out. Whatever the method
returns becomes the tool's result.
