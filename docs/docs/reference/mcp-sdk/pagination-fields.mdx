Returns the `limit` and `offset` input fields of a list tool, to spread into a Zod object.
`limit` accepts 1 to [MAX_LIST_PAGE_SIZE](/reference/mcp-sdk/max_list_page_size#max_list_page_size) and defaults to 25. `noun` names the items
in the field descriptions, such as "customers". See [page](/reference/mcp-sdk/page#page) for an example.

```ts title="Signature"
function paginationFields(noun: string): {
    limit: z.ZodOptional<z.ZodNumber>;
    offset: z.ZodOptional<z.ZodNumber>;
}
```
