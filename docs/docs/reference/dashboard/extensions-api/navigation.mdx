<MemberInfo kind="property" type={`(ctx: <a href='/reference/dashboard/extensions-api/navigation#dashboardusercontext'>DashboardUserContext</a>) => boolean`}  since="3.8.0"  />

A predicate evaluated on every nav render to decide whether this section is
shown. When it returns false the section and all of its items are hidden.

individual item is still applied to the items inside the section.

Presentation only, never authorization.

## setNavVisibility

Returns a new config in which the entries with the given ids have `predicate` ANDed
onto their existing `isVisible`. Matches both sections and nested items.

Use this rather than spreading `isVisible` yourself: a plain spread silently
discards a predicate that another plugin already set on the same entry.

This controls presentation only and is never an authorization mechanism.

*Example*

```ts
navMenuTransforms: [
    (config, ctx) => setNavVisibility(config, ['products'], () => !isFloorStaff(ctx)),
]
```

`isVisible` predicates so they can decide what this user should see.
