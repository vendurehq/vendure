## DashboardCommandPaletteItemDefinition

<GenerationInfo sourceFile="packages/dashboard/src/lib/framework/extension-api/types/command-palette.ts" sourceLine="153" packageName="@vendure/dashboard" since="4.0.0" />

An entry of the ⌘K command palette, added by a Dashboard extension. The palette lists it
next to the pages of the nav menu, and finds it by its title and keywords.

An entry either opens a page (`url`, see [DashboardCommandPaletteLinkItem](/reference/dashboard/extensions-api/command-palette#dashboardcommandpalettelinkitem)) or runs
an action (`onSelect`, see [DashboardCommandPaletteActionItem](/reference/dashboard/extensions-api/command-palette#dashboardcommandpaletteactionitem)). The type accepts
exactly one of them.

*Example*

```ts
import { defineDashboardExtension } from '@vendure/dashboard';
import { Star } from 'lucide-react';

defineDashboardExtension({
    commandPaletteItems: [
        {
            id: 'pending-reviews',
            title: 'Pending reviews',
            icon: Star,
            keywords: ['moderation', 'ratings'],
            group: 'catalog',
            url: '/reviews?status=pending',
            requiresPermission: 'ReadCatalog',
        },
    ],
});
```

```ts title="Signature"
type DashboardCommandPaletteItemDefinition = | DashboardCommandPaletteLinkItem
    | DashboardCommandPaletteActionItem
```
## CommandPaletteProvider

<GenerationInfo sourceFile="packages/dashboard/src/lib/components/layout/command-palette.tsx" sourceLine="63" packageName="@vendure/dashboard" since="4.0.0" />

Holds the ⌘K command palette of the Dashboard: the dialog and the Mod+K shortcut. The
Dashboard's app layout renders it, so an extension does not need to. The shortcut lives
here, not in the top bar trigger, so it keeps working when an extension replaces the
`search` toolbar item.

The palette lists the pages of the nav menu and the entries of
`commandPaletteItems` in `defineDashboardExtension`.

<div className="members-wrapper">

### id

<MemberInfo kind="property" type={`string`}   />

A unique id for the entry. An entry registered later with the same id replaces it.
### title

<MemberInfo kind="property" type={`string`}   />

The text of the entry. Like a nav menu item title, it is passed through the
Dashboard's translations, so a message id of your extension's catalog works.
### icon

<MemberInfo kind="property" type={`LucideIcon`}   />

An optional icon, imported from `lucide-react`.
### keywords

<MemberInfo kind="property" type={`string[]`}   />

More words the search matches, besides the title and the group heading.
### group

<MemberInfo kind="property" type={`string`}   />

The group of the palette to list the entry in. The palette has one group per nav menu
section: use the id of a section (such as `'catalog'`, see `BUILT_IN_NAV_SECTION_IDS`,
or the id of one of your `navSections`) to list the entry with the pages of that
section. Any other value starts a group of its own, with the value as its heading.

Without a group, the entry is listed with the top-level pages.
### order

<MemberInfo kind="property" type={`number`}   />

The position of the entry among the extension entries of its group. A lower number
comes first. Entries without an order come last, sorted by title. Extension entries
always follow the pages of the nav menu.
### requiresPermission

<MemberInfo kind="property" type={`string | string[]`}   />

Restricts the entry to administrators with the given permission or permissions. The
administrator needs ANY of them on the active channel, as for a nav menu item.
