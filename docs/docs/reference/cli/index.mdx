The reference of the `vendure` commands that `@vendure/cli` declares with `defineCommand`. It is generated from the command manifest of the CLI, `vendure-commands.json`.

Run `vendure commands --json` in a project for the commands it really has, including those that plugins add, and `vendure guide` for how an agent works with the CLI.

## Options of every command

| Option | Description |
| ------ | ----------- |
| `--json` | Write one JSON document to stdout, and events to stderr. `--format json` is an alias. |
| `--input <json\|->` | Pass the whole input as a JSON document, or read it from stdin with `-`. |

With `--json`, a command writes one envelope: `{ schemaVersion, status, output, needs, error, notices }`. `status` is `ok`, `failed`, `incomplete` or `error`. See [JSON output for scripts and agents](/guides/developer-guide/cli/#json-output-for-scripts-and-agents).

## Commands described in the CLI guide

These commands are not declared with `defineCommand` yet, so they have no generated reference. The [CLI guide](/guides/developer-guide/cli/) describes them, and `vendure <command> --help` lists their options.

- `vendure add`: Add a feature to your Vendure project. Its subcommands are on the [`vendure add`](/reference/cli/add) page.
- `vendure dev`: Run Vendure in development mode.
- `vendure build`: Build a Vendure project.
- `vendure start`: Start a built Vendure project.
- `vendure migrate`: Generate, run or revert a database migration. Its subcommands are on the [`vendure migrate`](/reference/cli/migrate) page.
- `vendure codemod`: Run codemods to update your Vendure project code.
- `vendure schema`: Generate a schema file from your GraphQL APIs.
- `vendure console`: Link this Vendure project to Vendure Console.
- `vendure auth`: Sign in to your Vendure account.
- `vendure plugins`: List, enable, or disable CLI plugins.
- `vendure mcp`: Run the Developer MCP server over stdio. Its subcommands are on the [`vendure mcp`](/reference/cli/mcp) page.
