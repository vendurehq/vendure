# Vendure McpPlugin

The `McpPlugin` exposes Vendure's data and operations to AI agents via the [Model Context Protocol](https://modelcontextprotocol.io/).

`npm install @vendure/mcp-plugin`

For documentation, see [docs.vendure.io/reference/core-plugins/mcp-plugin/](https://docs.vendure.io/reference/core-plugins/mcp-plugin/)
