# Vendure TelemetryPlugin

The `TelemetryPlugin` instruments your Vendure server and collects traces and logs using [OpenTelemetry](https://opentelemetry.io/).

`npm install @vendure/telemetry-plugin`

For documentation, see [docs.vendure.io/reference/core-plugins/telemetry-plugin/](https://docs.vendure.io/reference/core-plugins/telemetry-plugin/)
