# @vendure/mcp-sdk

This package contains the `@McpTool` decorator and helpers for writing custom MCP tools in Vendure plugins. The tools are served by the [`@vendure/mcp-plugin`](https://www.npmjs.com/package/@vendure/mcp-plugin).

`npm install @vendure/mcp-sdk`

For documentation, see [docs.vendure.io/reference/mcp-sdk/](https://docs.vendure.io/reference/mcp-sdk/)
